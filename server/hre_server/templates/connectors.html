AI 連携

Claude・ChatGPT などの AI アシスタントやエージェントから、人間関係グラフを読み書きできます（MCP サーバー）。 AI 側にこの URL を登録すると、この画面のログインと許可画面が開き、許可するだけで接続できます。

接続先 URL

Claude（claude.ai・デスクトップ・スマホ）
設定 → コネクタ → カスタムコネクタを追加 → 上の URL を入力して「接続」。OAuth Client ID / Secret は空のまま
ChatGPT
設定 → アプリとコネクタ（開発者モードを有効化）→ 作成 → 上の URL を入力し、認証は OAuth
Claude Code・Gemini CLI・Cursor など
HTTP の MCP サーバーとして上の URL を追加すると、初回接続時にブラウザで許可画面が開きます （例: claude mcp add --transport http hre {{ mcp_url }} のあと /mcp で認証）。 OAuth に対応していないツールや、KAGURA STAGE のようなサーバーは、エージェントの hre_ トークンを Authorization: Bearer ... で送ります{% if me.is_admin %}（トークンはアクセス管理で発行）{% endif %}。

AITuber ごとにエージェント（身元）を分けておくと、許可画面でそのエージェントを選ぶだけで、 その AITuber の視点・権限で動きます。記録者もそのエージェントになります。
